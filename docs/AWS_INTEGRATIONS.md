# AWS integrations

Every AWS service SureSay uses: where the code calls it, what permission it needs, and how to check it yourself. Region us-east-1. "Live" means it has been exercised on the deployed stack; "blocked" means the code is built and tested, but this account cannot call the service yet (see [FRICTION_LOG.md](FRICTION_LOG.md)).

| Service | What it does | Code | IAM (hub role unless noted) | Verify | Status |
|---|---|---|---|---|---|
| **Amazon Transcribe** (streaming) | Recognises each spoken request, primed with a per-user custom vocabulary from the phrasebook; transcribes the user's own confirmation audio on the server | `suresay/asr.py` `TranscribeStreamingAsr`, `VocabularyManager`; `suresay/hub.py` `evidence_transcribe` | `transcribe:StartStreamTranscription`, `GetVocabulary`, `CreateVocabulary` | `make smoke`, then a voice turn: `python infra/smoke.py <url>`; `eval/latency.py --hub-url` | Live: 825 ms p50 recognition in Lambda (understand total 870 ms) |
| **Amazon Transcribe** (eval) | Every TORGO clip for Claims 1, 2 and 5, per-speaker custom vocabularies, dev-only tuning | `eval/asr_cache.py` (`transcribe-streaming`), `eval/tune_*.py`, `eval/run_*_eval.py` | your CLI user | `make eval` | Live: 2,561 Transcribe requests in all (`eval/results/spend.json`) |
| **Amazon Bedrock**: Nova 2 Lite | Ranks the three most likely meanings, JSON output checked against the action catalog, abstains when unsure; also the agent's model | `suresay/rank.py` `NovaRanker` (Converse, temperature 0); `strands_agent/core.py` `BedrockModel` | `bedrock:InvokeModel`, `bedrock:Converse` on `us.amazon.nova-2-lite-v1:0` | `aws bedrock-runtime converse --model-id us.amazon.nova-2-lite-v1:0 …` | Authorized, but every Nova 2 Lite quota is 0 (increase requests pending); unit-tested with a stubbed client in `tests/test_rank.py` |
| **Amazon Bedrock**: Nova 2 Sonic | A second recogniser: a clip streamed as the user's turn comes back as the user's own words; the stream closes before Sonic replies, so only input tokens are billed. Also the **live AI** in the Alexa+ view: `suresay/hub.py` `/device/assistant` gives `SonicToolAgent` (`strands_agent/sonic.py`) SureSay's MCP tools; live: 0 / 27 changes without the user, 16 turns adversarial (`eval/results/live_assistant.json`). And a **ranker**: `suresay/rank.py` `SonicRanker` sends Nova 2 Lite's prompt and takes the ranking as a `submit_ranking` tool call (`SURESAY_RANKER=sonic`); 400 calls, $0.59 (`eval/results/sonic/run1/intent.json`) |

## One command

```bash
make deploy     # creates or updates everything above; the agent falls back to direct answers while Nova 2 Lite quota is 0
make smoke      # end to end over HTTPS: pair, three cards, confirm, the agent's confirm refused, protocol 2025-11-25
make teardown   # removes only suresay-* resources
```

## Spend so far

About $7.75: Transcribe requests (15-second minimum each, about $6.40), Nova 2 Sonic as a recogniser ($0.76) and as a ranker ($0.59). The running tally is in `eval/results/spend.json`. Live-assistant turns (short Nova 2 Sonic text turns, capped per day) are not in that tally.
